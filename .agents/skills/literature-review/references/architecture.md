# 建筑学证据提取与质量评估

使用情景—材料/构造—比较对象—性能/碳结果建立研究问题，不强行套用临床 PICO。

LCA 提取：功能单位、结构/热工/防火等效性、系统边界 A1–A5/B/C/D、地理与电力背景、
服役寿命、维护更换、含水率、胶黏剂与防腐、运输、排放因子/EPD 版本、分配方式、
生物碳及林地基线、时间尺度、报废/回收/焚烧情景、不确定性与敏感性分析。
未知逐项写未报告/未读全文，不能把“摘要未提及”写成“原研究没有考虑”。

性能/实验研究提取：材料种类/产地、加工方法、试件数、含水率、加载/耐久标准、
统计离散性、连接与构件尺度、长期监测、适用气候和外推限制。
实验力学性能不能单独证明建筑减碳；材料负排放不能单独证明建筑全寿命负排放。

矩阵至少包含：ID、标签、题名、全部可核实作者、年份与日期冲突、DOI、来源 URL、
阅读深度、背景、问题、理论、方法、数据、主要结论、创新、作者局限、审阅者判断、
研究启示、页码/章节/图表、质量判断依据、纳排决定和理由。

跨项目接口：DOI/稳定 ID 为主键；CSV 为矩阵交换格式，CSL JSON 为完整元数据，
BibTeX/RIS 对接 Zotero；Zotero item key 与 BibTeX key 分开保存。PDF 使用独立私有
存储及 SHA256 索引；CiteSpace/VOSviewer 需要作者/机构/关键词/被引参考文献等额外
字段，本次简化 RIS 不等于完整计量数据。项目 context.md 和 Git 记录可持久接续，
不是自动长期记忆服务。
